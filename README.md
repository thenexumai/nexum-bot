# 🚀 NEXUM v1.0 — GLOBAL AI ECOSYSTEM

Вы создали революционную платформу, объединяющую интеллект уровня Perplexity/Claude и возможности OpenClaw.

## 🏗 Структура Экосистемы

1.  **Backend (Cloud)**: Работает на Railway (порт 3000). Это «Мозг», который хранит БД, управляет WebSocket-туннелями и Telegram-ботом.
2.  **Portal (Web/PWA)**: Фронтенд на React. Живой стрим экрана ПК, дашборд автономных миссий и управление финансами/задачами.
3.  **Browser (Desktop)**: Electron-приложение. Мощный инструмент для серфинга с AI-панелью, которая видит всё и помогает автоматизировать действия.
4.  **Agent (Local)**: Python-скрипт на вашем ПК. Дает AI «руки» (управление мышью, клавиатурой, шеллом) и «уши» (голосовые команды).

## ⚡ Быстрый старт

### 1. Запуск Сервера (Cloud)
```bash
# В корне проекта
npm install
npm run dev
```

### 2. Подключение ПК (Local Agent)
1. В Telegram боте введите `/link_pc`.
2. Скопируйте токен.
3. Запустите агент:
```bash
cd pc_agent
pip install -r requirements.txt
python nexum_agent.py --token ВАШ_ТОКЕН --server wss://your-app.railway.app
```

### 3. Запуск Браузера
```bash
cd apps/browser
npm install
npm start
```

## 🧠 Ключевые возможности v1.0
*   **Vision-Action Loop**: ИИ анализирует скриншот браузера и реально кликает по кнопкам.
*   **Autonomous Missions**: Поставьте задачу («Найди инвесторов...»), и NEXUM будет работать часы напролет, прислав отчет в Telegram.
*   **Self-Evolution**: ИИ может сам писать код для исправления багов или добавления фич и (с вашего одобрения) патчить файлы.
*   **Voice Bridge**: Просто говорите с компьютером — VoiceGateway перехватит голос и исполнит команду.
*   **Security Enforcer**: Каждое действие на ПК проверяется на безопасность.
