# NEXUM - ЧАСТЬ 1: Исправление команд и персонализированное меню

## ЧТО СДЕЛАНО

### 1. Персонализированное меню команд
- ✅ Разделены команды для админов и обычных пользователей
- ✅ Админские команды помечены как [ADMIN]
- ✅ При `/start` каждому пользователю устанавливается персональное меню
- ✅ Админы видят все команды, пользователи - только свои

### 2. Изменённые файлы

#### `src/telegram/commands/index.ts`
- Добавлены два списка команд: `USER_COMMANDS` и `ADMIN_COMMANDS`
- Создана функция `setPersonalizedCommands(bot, userId)` 
- Теперь меню команд устанавливается индивидуально для каждого пользователя

#### `src/telegram/commands/general.ts`
- В команду `/start` добавлен вызов `setPersonalizedCommands`
- Это гарантирует, что каждый пользователь видит правильное меню

## КАК ПРИМЕНИТЬ

### Вариант 1: Автоматическое слияние (рекомендуется)
```bash
cd /path/to/nexum-bot-main
cp -r /path/to/PART1/* .
```

### Вариант 2: Ручное слияние
Скопируйте содержимое файлов:
1. `src/telegram/commands/index.ts` → заменить полностью
2. `src/telegram/commands/general.ts` → заменить только функцию `bot.command('start', ...)`

## ПРОВЕРКА РАБОТЫ

1. Запустите бота: `npm start`
2. Как обычный пользователь:
   - Отправьте `/start`
   - Нажмите `/` в Telegram
   - Должны видеть только пользовательские команды (без [ADMIN])
   
3. Как админ:
   - Отправьте `/start`
   - Нажмите `/` в Telegram
   - Должны видеть все команды включая [ADMIN]

## ТЕКУЩИЙ СТАТУС АДМИНА

Админ определяется в `src/core/config.ts` через функцию `isAdmin(uid)`.
Убедитесь, что ваш UID добавлен в список админов в CONFIG.
