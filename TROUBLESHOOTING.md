## 🐛 ПРОБЛЕМА: Бот не отвечает на сообщения

### Возможные причины:

#### 1. Нет API ключей для AI моделей ❌

**Симптомы:**
- Бот молчит после отправки сообщения
- Команды работают, но на обычные сообщения не реагирует
- В логах: ошибки про API ключи

**Решение:**

Проверь переменные окружения на Railway:

```bash
CB1, CB2, CB3, CB4, CB5, CB6  # Cerebras API ключи
GR1, GR2, GR3, GR4, GR5, GR6, GR7  # Groq API ключи
DS1, DS2, DS3, DS4, DS5, DS6  # DeepSeek API ключи
G1, G2, G3, G4, G5, G6, G7  # Google Gemini ключи
```

Должен быть **хотя бы один провайдер** с рабочими ключами!

---

#### 2. Превышен лимит сообщений 📊

**Симптомы:**
- Бот отправляет сообщение: "Лимит сообщений исчерпан (50/день)"

**Решение:**

Проверь свой план:
```
/status → смотришь сколько сообщений осталось
```

Варианты:
- Free: 50 сообщений/день
- Middle: 200 сообщений/день  
- Pro: без лимитов

Чтобы сбросить счётчик (только для Owner):
```sql
-- Подключись к БД на Railway
UPDATE users SET msg_count_today = 0 WHERE uid = 387182659;
```

---

#### 3. Проблема с базой данных 💾

**Симптомы:**
- В логах ошибки типа "SQLITE_ERROR"
- Бот запускается, но ничего не работает

**Решение:**

Проверь что таблицы созданы:
```bash
# На Railway
railway run sqlite3 data/nexum.db "SELECT name FROM sqlite_master WHERE type='table';"
```

Должны быть таблицы:
- users
- sessions
- tasks
- reminders
- byok_keys
- pc_agent_tokens
- (и другие)

Если таблиц нет — база не инициализирована. Перезапусти бот.

---

#### 4. Бот падает при старте 💥

**Симптомы:**
- В Railway логах видно ошибку и бот рестартится

**Проверь логи:**
```bash
railway logs
```

Частые ошибки:
- `BOT_TOKEN not set!` → не установлен BOT_TOKEN
- `Cannot find module` → не запущен `npm run build`
- `SQLITE_CANTOPEN` → нет доступа к data/nexum.db

## 🔧 ПРОБЛЕМА: Команды не появляются в меню

### Причина: Старые команды кешированы в Telegram

**Решение 1: Обновить команды через /start**

```
1. Открой чат с ботом
2. Отправь /start
3. Подожди 5 секунд
4. Проверь меню команд (кнопка "/" слева от поля ввода)
```

Бот должен автоматически установить персонализированные команды:
- Free → базовые команды
- Pro → базовые + /byok, /link_pc, /pc_status
- Owner (UID 387182659) → все команды + /fix, /improve, /diag

**Решение 2: Удалить и добавить бота заново**

```
1. Удали бота из чата (или заблокируй)
2. Найди бота заново
3. Отправь /start
4. Команды обновятся
```

**Решение 3: Принудительная очистка (если выше не помогло)**

Отправь боту команду напрямую (без автодополнения):
```
/deleteMyCommands
```

Затем:
```
/start
```

## 📝 ЧАСТЫЕ ВОПРОСЫ

### Q: Бот отвечает на команды, но не на обычные сообщения

**A:** Проверь API ключи. Нужен хотя бы один рабочий ключ от AI провайдера.

```bash
# Проверь что ключи установлены
railway variables
```

### Q: Команды в меню старые / не те

**A:** Telegram кеширует команды. Решения:
1. Отправь /start
2. Удали бота и добавь заново
3. Перезапусти бот на Railway

### Q: Бот работает, но медленно

**A:** Возможные причины:
- Railway спит (бесплатный план засыпает после бездействия)
- API ключи израсходованы / rate limit
- Модель перегружена

### Q: Как проверить что бот вообще работает?

**A:** 
```bash
# Проверь health endpoint
curl https://твой-домен.railway.app/health

# Должен вернуть:
{"ok":true,"uptime":123,"version":"1.0.0","agents":0}
```
