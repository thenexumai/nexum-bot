# NEXUM Self-Improve System

Nexum может анализировать собственный код и предлагать улучшения через Telegram.

## Как работает

1. Пользователь или сам Нексум вызывает `analyzeAndPropose(filePath, request, uid, bot)`
2. AI читает текущий код файла из GitHub
3. AI генерирует улучшенную версию
4. Предложение отправляется **админу** в Telegram с кнопками ✅/❌
5. При одобрении — файл пушится на GitHub через GitHub API
6. Railway видит новый коммит и автоматически деплоит

## Команды в боте

- `/improve <путь_к_файлу> <описание>` — предложить улучшение файла
- `/patches` — список ожидающих патчей (только для админов)

## Переменные окружения

Добавь в Railway:
```
GITHUB_TOKEN=ghp_xxxxxxxxxxxxxx
```
Токен должен иметь права: `repo` (read + write).

## Безопасность

- Только **ADMIN_IDS** могут одобрять патчи
- Каждый патч имеет уникальный ID
- Все действия логируются через Logger
